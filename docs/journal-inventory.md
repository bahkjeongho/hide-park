## 8. 기타 확인 사항

- `aliases`, `tags`, `Related`의 빈 값은 문자열 `[]`로 적혀 있습니다(빈 YAML 목록 표기).
- `Countries` 속성은 60개 노트 모두 있지만 값은 1개 노트(`[[UK]]`)에만 있고 59개는 비어 있습니다. 실제 국가 값은 `Country/Region`(58개 노트)에 있습니다.
- 같은 개념으로 보이는 변형 속성(`subject_area`, `research_orientation`, `Country/Region`)을 목표 속성(`Subject Area`, `Orientation`, `Countries`)으로 합칠지는 지시문의 '대소문자만 다른 경우' 규칙에 해당하지 않아, 2단계 전에 결정이 필요합니다.
- 삭제로 사라지는 값이 있는 속성: `title` 57개 노트(제목 텍스트), `IG`·`Website` 각 1개 노트(Antikythera로 보이는 노트). `aliases`, `Wikis`, `Cities`는 값이 없습니다.
- 형식이 다른 노트: `2. Wiki/AA Files (AAF).md` 1개는 이미 목표 이름(`Subject Area`, `Orientation`, `Countries`)과 `[[ ]]` 값을 쓰고 있습니다(나머지 59개는 소문자·밑줄 이름). `IG`·`Website` 값이 있는 노트는 `2. Wiki/Antikythera.md`, `2. Wiki/Antikythera Journal (Antikythera).md` 입니다.
- 볼트 전체에서 `topic`에 `Journal`이라는 글자가 들어 있으나 `[[Journal]]`이 아닌 노트 4개(Luke Leitch, Hearing Things, Anthony Fantano, A.G. Sulzberger)는 `Journalism`/`Journalist` 등 다른 토픽이라 대상에서 제외했습니다.
